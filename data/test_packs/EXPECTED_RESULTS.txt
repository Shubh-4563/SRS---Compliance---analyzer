IMPORTANT
1. These are synthetic starter documents, not validated real-world benchmarks.
2. “Expected” labels are human judgments about content, not guaranteed model outputs. Similarity thresholds can misclassify partial content.
3. Compare the analyzer's evidence snippets to the actual target paragraphs. Generic title/heading text should not be accepted as strong evidence for a required point.
4. Start with Pair B. If the analyzer gets the clear present/missing cases wrong, fix extraction/matching before tuning thresholds or adding OCR.
5. The current PDF text extractor should work on these digitally generated PDFs. Image/OCR testing is a separate later phase.
